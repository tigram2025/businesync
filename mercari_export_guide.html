📊 メルカリ 月別売上CSV出力

個人アカウントの取引履歴を月別CSVに出力するスクリプト

1Pythonをインストール

Python 3.11以上が必要です。

python.org からダウンロードしてインストール。

2Playwrightをインストール

ターミナル（コマンドプロンプト）で以下を実行：

pip install playwright
python -m playwright install chromium

3スクリプトをダウンロード

mercari_export.py をPCの任意のフォルダに保存してください。

4スクリプトを実行

python mercari_export.py

対象年・月を入力 → ブラウザが開く → メルカリにログイン → Enterキーで収集開始

💡 SMS認証や二段階認証も手動で完了してからEnterを押してください。パスワードはスクリプトに保存されません。

5CSV出力される内容

列名内容
取引日時売却が完了した日時
商品名出品した商品のタイトル
カテゴリ商品カテゴリ
売上金額(円)購入者が支払った金額
手数料(円)メルカリ手数料（10%）
送料(円)送料負担分
振込金額(円)実際の振込見込み額

出力ファイル例: mercari_sales_202601.csv

⚠うまく動かない場合

メルカリのページ構造が変わった場合、debug_page.html が生成されます。 そのファイルをブラウザで開き、実際のHTML要素を確認してセレクタを調整してください。

このスクリプトはご自身のアカウントのデータのみを取得するものです。メルカリの利用規約の範囲内でご利用ください。
