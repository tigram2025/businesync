# メルカリ売上CSV出力（Chrome拡張機能）

Python不要。Chromeに拡張機能を読み込んで、取引履歴ページでボタンを押すだけでCSVが出力されます。

## インストール手順

1. このフォルダ（`mercari-extension`）をPCにダウンロード・保存する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `mercari-extension` フォルダを選択する

## 使い方

1. `jp.mercari.com` にログインする
2. マイページ →「売上・振込申請」または「取引履歴」など、売れた商品の一覧が見えるページまで移動する
3. ツールバーの拡張機能アイコンをクリックして「このページの売上をCSV出力」を押す
4. CSVがダウンロードされる

## うまくいかない場合

「うまくいかない時：HTMLを保存」ボタンを押すと、現在のページのHTMLが `debug_page.html` としてダウンロードされます。
それを共有すれば、ページ構造に合わせて抽出ロジックを調整できます。

## 仕組み

ページ内で「¥」を含む価格表示が一定数並んでいる `<ul>` / `<ol>` 要素を取引一覧とみなし、
各項目から日付・商品名（画像のalt属性）・価格を抽出します。手数料はメルカリの標準手数料率10%で計算しています。
