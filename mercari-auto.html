🤖 メルカリ自動出品アシスト

できること

  • 写真を最大10枚、メルカリの出品画面へ自動アップロード
  • 角・付属品などの写真は4枚ずつ 2×2 の1枚に自動合成
  • 写真とメモ（ブランド・管理番号・サイズ）から OpenAI がタイトルと説明文を作成
  • 返品対応・購入元の定型文を説明文の末尾に自動で付ける
  • ChatGPT で作った文章（【タイトル】【商品説明】）をそのまま貼れば自動で振り分け

「出品する」ボタンは自動では押しません。カテゴリ・状態・配送・価格を確認してからご自身で押してください。

① インストール（初回だけ）

  1. PCの Chrome / Edge に拡張機能 Tampermonkey を入れる
    （iPhone/iPad の Safari なら App Store の「Userscripts」アプリでも動きます）
  2. 下のボタンを押して「インストール」
スクリプトをインストール

② 使い方

  1. メルカリの 出品画面 を開くと、右下に「🤖 自動出品」ボタンが出ます
  2. 初回は ⚙️設定 に OpenAI APIキーを入れて保存
  3. そのまま使う写真（正面・背面・側面など）をドロップ
  4. 4分割にまとめる写真（角4か所・付属品など）をドロップ → 4枚ずつ自動合成
  5. メモ欄にいつも ChatGPT に送っている内容を入力
    ロエベ クロコ / 管理番号 127-3 / 縦 19cm / 横 24.3cm / マチ 16cm / ハンドル 9.5cm
  6. 「✨ AI生成」→ 内容を確認・修正
  7. 「⬇️ メルカリの出品画面に入力」→ 残りの項目を設定して出品

写真は ◀ ▶ で並べ替え、✕ で削除できます。合計が10枚を超えた場合は、4分割を優先して残し、そのまま使う写真の後ろから省きます。

うまく入らないとき

  • メルカリの画面が変わると入力欄を見つけられないことがあります。パネルに「❌ ○○の欄が見つかりません」と表示されたら教えてください
  • APIキーはお使いのブラウザ内にだけ保存され、OpenAI 以外には送られません
